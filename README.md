# Pattern Gallery

유니티 개발자 양성과정의 **게임 프로그래밍 패턴 갤러리**. 패턴 없이 짠 흔한 코드(효과 끄기)와 패턴을 쓴 코드를 같은 입력으로 돌려 보고, 구조 그림과 코드 줄을 단계별로 따라가고, AI 지시 세트로 같은 구조를 Unity 프로젝트에 넣는다.

- 기준: Unity 6.3 LTS, C# 9, 새 Input System
- 게임 규칙은 UnityEngine 을 쓰지 않는 순수 C# 코어에 있고, 웹 무대는 그 코어를 옮긴 시뮬레이션이다. 같은 시나리오를 dotnet 으로 실제 C# 에 돌린 기록과 웹의 기록을 줄마다 대조한다.
- 결과물은 HTML 파일 하나다. 더블클릭(file://)으로도, GitHub Pages 로도 같게 동작한다.

문서: [계획](docs/plan.md) · [인수인계](docs/handoff.md) · [표본 제작 가이드](docs/specimen-guide.md) · [표본 선정](docs/selection.md). 공통 틀은 [edu-lecture-gallery-kit](https://github.com/KooHoo-Dev/edu-lecture-gallery-kit).
